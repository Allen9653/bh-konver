## English Version: Note for Reviewers, Quality Evaluators & AdSense/Store Moderators

### 1. Full English Localization Support
BH KONVER provides **100% full English localization** across all web platform modules, tools, and documentation. All user interfaces, instructional copy, input validation errors, toast notifications, PDF generators, calculators, knowledge tests, and legal policies are comprehensively translated and fully functional in English.

### 2. Direct English Access Links
Reviewers and international evaluators can immediately access the platform in English using any of the following direct links:
- **Primary Direct English Link (URL parameter):**  
  [https://www.bh-konver.com/?lang=en](https://www.bh-konver.com/?lang=en)
- **Alternative Direct Path (Route alias):**  
  [https://www.bh-konver.com/en/](https://www.bh-konver.com/en/)
- Any sub-page or tool can also be opened directly in English by appending `?lang=en` (e.g., `https://www.bh-konver.com/category/generatori?lang=en`, `https://www.bh-konver.com/alati?lang=en`).

### 3. Automatic Geolocation & Browser Locale Detection
The platform has an intelligent client-side language detection engine:
- **Visitors from outside our local region (Bosnia and Herzegovina, Croatia, Serbia, Montenegro):**  
  The system automatically inspects `navigator.languages` and browser locale preferences. If the visitor's preferred locale is outside the local Balkan region (e.g., US, UK, Germany, France, Japan, etc.), **the application immediately loads in English** by default.
- **Local visitors (`bs`, `hr`, `sr`, `cnr`):**  
  Served the localized Bosnian/regional interface by default.
- **Manual override:**  
  The user can toggle their language preference at any time via the language selector dropdown in the navigation header or via direct links in the footer. The selected preference is persisted across sessions in `localStorage`.
